# Washington, D.C. Data Bundle

This bundle contains real public data staged for the routing backend:

- DC administrative boundary from DCGIS ArcGIS REST.
- OpenStreetMap DC extracts from Geofabrik.
- A processed DC walking GraphML generated by OSMnx.
- DDOT 2023 traffic volume lines.
- DC 2020 urban tree canopy summary and center raster tile.
- DC 2020 generalized land-cover center raster tile.
- NOAA-hosted DC OCTO 2022 LiDAR metadata, full-city DEM and all 328 raw COPC LAZ tiles.
- Full-city LiDAR-derived DSM, building DSM, vegetation CDSM and canopy-height rasters.
- Open-Meteo hourly meteorological forcing converted to SOLWEIG metfile format.

Large files are intentionally not committed to source control in most projects,
but they are present in this local workspace under `data/`.

Regenerate or update the bundle with:

```bash
python scripts/build_dc_data_bundle.py
```

Download all NOAA raw LiDAR tiles with:

```bash
python scripts/build_dc_data_bundle.py --download-all-laz
```

Build LiDAR-derived SOLWEIG inputs with:

```bash
python scripts/build_lidar_products.py
```

Run a real-data SOLWEIG-GPU smoke test with:

```bash
python scripts/run_solweig_gpu.py --date 2026-05-23 --met-file data\processed\solweig_inputs\met_forcing_2026-05-23_2026-05-23.txt --work-dir data\processed\solweig_gpu_smoke --subset-size-m 128 --tile-size 128 --clean-work-dir
```
