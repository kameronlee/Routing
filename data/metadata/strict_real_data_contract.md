# Strict Real-Data Routing Contract

The API must not fabricate route features in production/runtime mode.

Required layers:

- Local DC street graph: `data/processed/streets/dc_walk_graph.graphml`
- LiDAR-derived DEM: `data/processed/rasters/dem_1m.tif`
- LiDAR-derived tree canopy height raster: `data/processed/rasters/canopy_height_1m.tif`
- DDOT AADT traffic lines: `data/raw/traffic_noise/ddot_traffic_volume_2023.geojson`
- SOLWEIG/SOLWEIG-GPU UTCI raster: `data/processed/solweig_outputs/utci_YYYY-MM-DD_HH.tif`

Optional real supporting layers:

- DC land-cover rasters, when available, are used as extra scenic/water context.

Behavior:

- `/route` returns `503` when any required real layer is missing.
- `/utci` samples real UTCI rasters only.
- Development fallback data is available only when explicitly enabled with
  `ROUTING_ALLOW_SYNTHETIC_GRAPH=1` or `ROUTING_ALLOW_SYNTHETIC_MICROCLIMATE=1`.

Current bundle state:

- Streets, LiDAR DEM, full classified LiDAR canopy/building products and traffic layers are present.
- SOLWEIG-GPU is installed and validated on a real clipped subset.
- Full production UTCI/Tmrt rasters still need to be generated by SOLWEIG-GPU.
