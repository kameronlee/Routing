# GeoHealth experiment records

- `corrected/`: the revised paper's 10,000 routes, 1,600 sensitivity records,
  input/source checksums, figures, and analysis.
- `solver_validation/`: generated graphs and independent exact-reference checks.
- `raw/` and `analysis/`: historical records and their earlier reanalysis.
- `figure_inputs/`: frozen DC GIS context, used only for geographic display.

The original OD CSV is reused throughout. The corrected run is the paper's
primary experiment; historical outcomes are retained for audit.
