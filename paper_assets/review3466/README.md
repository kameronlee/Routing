# GeoHealth experiment records

- `sampling5/`: the primary 5 m run, full-cohort sampling comparison, and
  one-factor checks.
- `corrected/`: the complete 20 m reference run.
- `solver_validation/`: generated graphs and independent exact-reference checks.
- `raw/` and `analysis/`: historical records and their earlier reanalysis.
- `figure_inputs/`: frozen DC GIS context for geographic display only.

All routing comparisons reuse the same original OD CSV. Raw records,
checksums, and executed source preserve each run separately.
